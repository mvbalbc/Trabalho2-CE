\section{Objetivo}
\begin{frame}
\frametitle{Objetivo}
\justifying

\begin{itemize}
    \item  Este estudo realiza uma análise estatística descritiva focada
    em explorar o impacto das continuações no mercado indie.
    \vspace{0.2cm}

    \item Analisamos uma ampla base de dados de jogos indie para responder as 
    questões relacionadas à frequência, 
    popularidade e desempenho comercial das sequências e seus jogos anteriores. 
    \item Também analisamos o impacto do efeito em gêneros de jogos, para entender 
    se certos tipos de jogos são mais propensos a gerar engajamento.
    \vspace{0.2cm}

\end{itemize}    
\end{frame}

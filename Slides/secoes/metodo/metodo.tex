\section{Método}
\begin{frame}
\frametitle{Método}
\justifying

\begin{itemize}
    \item  Nossa pesquisa combina duas bases de dados complementares:
    uma ampla base com milhares de jogos indie para responder
    às questões 1 e 2, e uma base reduzida de 37 franquias
    para responder às demais questões mais específicas sobre o
    comportamento das sequência.
    \vspace{0.2cm}

    \item Foram coletados dados como número de donos, gêneros, avaliações, 
    datas de lançamento, nota média, entre outros, para realizar uma análise estatística descritiva e comparativa.
    \vspace{0.2cm}

\end{itemize}    
\end{frame}

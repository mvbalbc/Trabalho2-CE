\begin{frame}{1. Seleção de Casos (Amostragem)}
    \justifying
   Encontrar o volume elevado de estudos necessária para a análise.

    \vspace{0.8em}
    \begin{itemize}
        \item \textbf{Busca Sistemática:} Identificação de estudos de caso relevantes em bases de dados acadêmicas;
        \item \textbf{Critérios de Inclusão:} Definição de requisitos rígidos
        \item \textbf{Validação da Amostra:} Garantir que os casos selecionados contenham detalhes suficientes para serem codificados.
    \end{itemize}
    
\end{frame}

\begin{frame}{O que é o Case Survey?}
    \justifying
    O \textit{case survey} é um método de pesquisa que permite a integração de descobertas de múltiplos estudos de caso isolados.

    \vspace{0.8em}
    \begin{block}{Definição}
        Funciona como uma análise quantitativa de dados qualitativos, gerando insights de um conjunto grande de casos independentes.
    \end{block}

    \vspace{0.8em}
    \begin{itemize}
        \item Permite análise qualitativa de estudos de caso da literatura;
        \item Sintetiza o conhecimento disperso em diversos estudos isolados;
        \item Método "barato" de agregar informação de muitos casos.
    \end{itemize}
\end{frame}

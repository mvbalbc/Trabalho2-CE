\begin{frame}{2. Criação do Esquema de Codificação}
    \justifying
    Como converter texto em dados qualitativos.

    \vspace{0.8em}
    \begin{itemize}
        \item \textbf{Variáveis:} Definição de quais conceitos serão extraídos dos textos;
        \item \textbf{Escalas:} Uso de escalas binárias (Sim/Não) ou ordinais;
        \item \textbf{Livro de Códigos:} Documento detalhado que explica o que cada categoria significa para evitar ambiguidades.
    \end{itemize}

\end{frame}
